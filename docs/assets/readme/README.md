# The README's images

The repository's README shows these, each in a light and a dark version:

| File | What it is |
|---|---|
| `hero-*.svg` | The banner from [the brand](../brand/README.md), with its cells and words animated in once |
| `flow-*.svg` | How the family fits together, drawn with each package's own mark, its wires animated |
| `quickstart.svg` | The template's quick start, typed out once |

Every animation is plain CSS inside the SVG, so it plays where GitHub shows the image, and stops for anyone who prefers reduced motion. Text that isn't the brand's is set in the system's fonts, since an image can't load web fonts. When a package joins the family or the quick start changes, redraw these.
