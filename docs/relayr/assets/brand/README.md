# Brand

[ADR-0011](../../adr/0011-documentation-site-and-brand.md) records relayr's identity: it prints on one plate, magenta, the ink artifactr and reflexr share, and its mark is two strokes on the family's diagonal, whose overlap is its overprint and working colour. [`tokens.json`](tokens.json) holds its colours.

| File | What it is | Use it on |
|---|---|---|
| [`mark-light.svg`](mark-light.svg) | The mark | Light backgrounds |
| [`mark-dark.svg`](mark-dark.svg) | The mark | Dark backgrounds |
| [`lockup-light.svg`](lockup-light.svg) | The mark and the wordmark | Light backgrounds |
| [`lockup-dark.svg`](lockup-dark.svg) | The mark and the wordmark | Dark backgrounds |
| [`banner-light.svg`](banner-light.svg) | The README banner | Light backgrounds |
| [`banner-dark.svg`](banner-dark.svg) | The README banner | Dark backgrounds |
| [`favicon.svg`](favicon.svg) | The mark, switching to the dark colours when the system prefers a dark scheme | Browser tabs |
