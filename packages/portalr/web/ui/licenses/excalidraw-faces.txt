Excalidraw's typefaces, as portalr's app carries them beside the diagrams' canvas
(portalr ADR-0072)

The app copies Excalidraw 0.18.1's faces, as its package ships them, to excalidraw/fonts/, and
the canvas draws a diagram's words with them, but for Liberation Sans, which is Liberation 2.1.5
(lattice#679). The package ships no licence file for any of them. Each face's notice follows: for
Virgil, Assistant and Comic Shanns, as its name table holds it (copyright, trademark, licence and
the licence's URL), read from the faces the app carries; for the others, as its upstream
repository holds it, at the commit named.

## Liberation Sans

Liberation Sans 2.1.5, which this build ships in place of the Liberation Sans 1.05 that Excalidraw
0.18.1 carries: that one's name table refers to Ascender's licence agreement, not the SIL Open Font
License. Digitized data copyright (c) 2010 Google Corporation, with Reserved Font Arimo, Tinos and
Cousine. Copyright (c) 2012 Red Hat, Inc., with Reserved Font Name Liberation.
Licence: SIL Open Font License, Version 1.1, below.
Source: github.com/liberationfonts/liberation-fonts, tag 2.1.5
(4b0192046158094654e865245832c66d2104219e); LICENSE there, SHA-256
93fed46019c38bbe566b479d22148e2e8a1e85ada614accb0211c37b2c61c19b.
The face is LiberationSans-Regular.ttf of the release's liberation-fonts-ttf-2.1.5.tar.gz (SHA-256
7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0); the TTF's SHA-256 is
76d04c18ea243f426b7de1f3ad208e927008f961dc5945e5aad352d0dfde8ee8.
It is converted to WOFF2 with fontTools 4.62.1 and brotli 1.2.1 (`TTFont(ttf,
recalcTimestamp=False)`, `flavor = "woff2"`) and nothing else. No glyph, name or outline data is
changed: the decompiled glyphs, glyph order, names and character map equal the TTF's. WOFF2's
encoding re-encodes glyf and loca, sets head flag bit 11 and writes a new checkSumAdjustment. The
result, packages/portalr/web/ui/fonts/LiberationSans-Regular.woff2, has SHA-256
455f80807d01a6920a653ed102161cb886594fba540db52be52502f11fbf8322.
`packages/portalr/scripts/check_liberation.py` downloads the tarball, checks both checksums,
converts and compares. Both builds copy the result over Excalidraw's file.
Whether that conversion is "unchanged except for WOFF compression" in the sense of OFL-FAQ 2.2.1
is a reading, not settled by the FAQ (see below); it is unverified.

## Web fonts, embedding and Reserved Font Names: the OFL-FAQ, as read here

Read at https://openfontlicense.org/ofl-faq/ on 2026-10-24. Liberation (Reserved Font Name
Liberation), Lilita One (Lilita), Cascadia Code (Cascadia Code) and Xiaolai (see above) reserve
names; the builds keep every face's name.
- Entry 2.2 and 2.2.1: a WOFF/WOFF2 version may keep the name only if "the original font data
  remains unchanged except for WOFF compression" and WOFF metadata is omitted or complete. Entry
  2.2.2 adds that some conversion tools do not meet this. The Liberation conversion above is
  held to it by the checks listed there, but whether re-encoded glyf and loca, head flag bit 11 and
  a new checkSumAdjustment are "WOFF compression" is a reading, not stated by the FAQ: unverified.
  The other faces are Excalidraw's own WOFF2 files, whose conversion was Excalidraw's.
- Entry 2.6: removing parts of a font when delivering a webfont, "including unused glyphs", is
  modification, "permitted by the OFL but would not normally allow the use of RFNs".
- Entries 1.11 and 1.12: embedding a font in a document or file, "either in full or a subset", is
  not distribution, and the restrictions on modification and redistribution "do not apply, as the
  font is not intended for use outside the document". The worker's SVG exports embed subsets of
  the faces they use, among them Liberation, Lilita One and Cascadia Code, under their own names;
  the canvas's exports embed whole faces. That they are documents in the FAQ's sense, and not an
  extractable distribution of the font, is a reading, unverified.
