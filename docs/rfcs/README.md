# Requests for comments

The family's RFCs: proposals that change more than one package. An RFC proposes a substantial change before it is built, and ADRs, in [`adr/`](../adr/README.md) and each package's series, record the decisions it leads to. A change within one package is proposed in that package's own series, in `docs/<package>/rfcs/`, and stackr's RFC-0001 to RFC-0003 keep their numbers there.

Outside this series, an RFC is named as "lattice RFC-0001".

| RFC | Title | Status |
|---|---|---|
| [0001](0001-grantr-identity-and-access.md) | grantr, identity and access | Discussion |

A new RFC starts from a package's [template](../relayr/rfcs/template.md), until [#40](https://github.com/alexnodeland/lattice/issues/40) makes the templates one.
